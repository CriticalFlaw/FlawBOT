Commands for managing server users.

### avatar
Returns server user's profile picture. Defaults to your own.
```
/user avatar @CriticalFlaw
```

### ban
Bans a server user for a given day duration and reason.
```
/user ban @CriticalFlaw 7 Spammer
```

### info
Returns server user's information. Defaults to your own.
```
/user info @CriticalFlaw 
```

### unban
Unbans a user from the server, using their Discord user ID.
```
/user unban 339833029013012483
```
