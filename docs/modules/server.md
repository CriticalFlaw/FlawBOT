Commands for managing the Discord server.

### avatar
Changes the server avatar. Requires the Manage Server permission. The image must be a PNG, JPG or GIF under 10MB.
```
/server avatar https://frinkiac.com/img/S03E20/301341.jpg
```

### info
Returns server information.
```
/server info
```

### invite
Returns server invite link.
```
/server invite
```

### rename
Changes the name of the server. Requires the Manage Server permission.
```
/server rename Cool Discord Server 
```
